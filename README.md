# 🔥 Чёткий Краснодар — бесплатный бот для ВКонтакте

Отдельный проект для [сообщества «Чёткий Краснодар»](https://vk.ru/club243223484). Проекты Ярославля, Екатеринбурга и автомобильного сообщества не затрагиваются.

## Возможности
- До **30 коротких городских постов в сутки** по Краснодарскому времени (Москва, UTC+3): один пост в каждые 48 минут при наличии материала.
- Два бесплатных RSS-поиска Google Новости по Краснодару, фильтры свежести и города, защита от совпадающих ссылок и похожих заголовков.
- Пацанский дружелюбный стиль (Братва, Пацаны, Народ), ровно **3 новые тематические хэштега** с названием Краснодара.
- Если нет подходящей новости — короткая игра или вопрос в комментарии: любимые районы, парк Галицкого, Красная улица, обед, знакомства и т. д.
- Не более **4 интерактивных постов в день**, минимум 3 часа между ними, только 08:00–22:59 местного времени, один вопрос не повторяется 7 дней.
- История публикаций, ссылок и хэштегов хранится в `history.json`.
- **Без OpenAI API** и платных текстовых сервисов. Публичный GitHub Actions со стандартным раннером работает бесплатно в рамках условий GitHub.

## Подключение
1. Создайте ключ **сообщества ВК №243223484**, разрешающий публикацию на стене, в управлении этим сообществом → Работа с API → Ключи доступа.
2. В [секретах GitHub](https://github.com/76kovka76-hub/chetkiy-krasnodar-vk/settings/secrets/actions) добавьте секрет с именем **`KRASNODAR_VK_TOKEN`**, значение — ключ от этого сообщества. Не используйте токены других городов.
3. ID группы **243223484 уже прописан в коде**; второй секрет с ID не требуется.
4. Для сохранения истории включите `Settings → Actions → General → Workflow permissions → Read and write permissions`.

## Статус: реальные публикации включены
- В [главном workflow](https://github.com/76kovka76-hub/chetkiy-krasnodar-vk/blob/main/.github/workflows/publish.yml) стоит `DRY_RUN: "false"`: новые запуски по расписанию могут публиковать новости и интерактивные посты.
- [Проверка токена и источников](https://github.com/76kovka76-hub/chetkiy-krasnodar-vk/actions/runs/43254682495) подтвердила наличие `KRASNODAR_VK_TOKEN`, 18 тестов и доступность обеих RSS-лент.
- **Первая реальная публикация подтверждена:** [https://vk.com/wall-243223484_1](https://vk.com/wall-243223484_1). [Логи первого поста](https://github.com/76kovka76-hub/chetkiy-krasnodar-vk/actions/runs/43254877429).
- До 30 записей в сутки, по одной на 48-минутный временной слот. При отсутствии свежей городской новости возможен вопрос для подписчиков — до 4 таких постов в сутки, с ограничениями по времени.
- [Следить за автоматическими запусками](https://github.com/76kovka76-hub/chetkiy-krasnodar-vk/actions/workflows/publish.yml); [смотреть историю публикаций](https://github.com/76kovka76-hub/chetkiy-krasnodar-vk/blob/main/history.json).
- Для остановки верните `DRY_RUN: "true"` в workflow или отключите workflow в GitHub Actions. Первая публикация проверила права токена; работа расписания на протяжении суток пока ещё не подтверждена.

## Ограничения
- **30 постов — верхний предел**, не гарантия: при отсутствии новостей и подходящих игр бот пропускает слот.
- Новости основаны на реальных RSS-заголовках, но бесплатный шаблонизатор не заменяет редактора и не гарантирует устранение всех смысловых дублей.
- Ленты Google Новости могут меняться или временно становиться недоступными. GitHub Actions cron также может запускаться с задержкой.
- Чужие фотографии автоматически не публикуются.
